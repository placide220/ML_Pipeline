# models/

Put the trained model artefacts from Task 1C here (they are NOT generated by the API code):

| File | Required | How to create it (in the training notebook) |
|---|---|---|
| `best_model.joblib` | yes | `joblib.dump(best_model, "models/best_model.joblib")` |
| `feature_columns.json` | yes | `json.dump(list(X_train.columns), open("models/feature_columns.json", "w"))` |

Notes
- Save the exact column order used in training; `scripts/predict.py` reorders features to match it.
- If the target was `log1p`-transformed, run predict with `--log-target`.
- If the model file is large (>50 MB), keep it out of git (add it to `.gitignore`) and describe how to regenerate it in the README.
- After adding the files run `python scripts/check_features.py`.

Feature naming
- `scripts/predict.py` builds lag/rolling columns with `add_lags` / `add_rolling` from `time_series_features.py`
  and reads the lags, windows and column prefix (e.g. `global_active_power_kw_lag24`) from `feature_columns.json`.
- Calendar features are not in that helper, so `calendar_features()` in `predict.py` must produce the same names
  your training notebook used (default: hour, day_of_week, is_weekend, month). `check_features.py` tells you if not.
